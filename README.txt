Container Trade — вёрстка (HTML / SCSS / jQuery 4 + Swiper 11) под OpenCart 4
============================================================================

Открыть: index.html — двойной клик, сервер не нужен.

  index.html              главная
  reviews.html            отзывы
  price.html              цены
  blog.html               блог (список статей)
  blog-article.html       статья блога
  contacts.html           контакты
  404.html                страница «не найдено»
  catalog.html            каталог «Морские контейнеры» (фильтр, сортировка, товары)
  catalog-reef.html, catalog-ot.html, catalog-pw.html, catalog-parts.html,
  catalog-rent.html       те же страницы каталога для остальных категорий —
                          отличаются первым экраном (цвет, картинка, текст, кнопки)
  product.html            карточка товара
  search.html             результаты поиска
  checkout.html           оформление заказа
  checkout-success.html   заказ принят

    _hero.scss              первый экран, фильтр, свой выпадающий список (.select)

    _sections.scss          секции главной, отзывы, блог, FAQ, SEO

    _footer.scss            подвал

                            таблицы цен/характеристик, статья, контакты, 404
    _catalog.scss           каталог: первый экран категории, фильтр, сортировка,
                            результаты поиска
    _product.scss           карточка товара, плавающая панель покупки
    _checkout.scss          оформление заказа, «Заказ принят»

  css/vendor/             Swiper, Leaflet
  js/main.js              вся логика (jQuery)
  js/ctmap.js             карты: наличие и расчёт доставки (главная), склады (контакты)
  js/vendor/              jQuery 4, Swiper 11, Leaflet 1.9
  img/                    картинки (WebP), img/icons — SVG
  video/                  видео первого экрана (без звука, служебные данные в начале файла):

  _src/                   шаблоны Jinja2, из которых собран HTML (по структуре

СБОРКА
  npm install                       (sass)
  python -m pip install jinja2      (шаблоны HTML)
  npm run build     — иконки + HTML из _src + style.css + style.min.css
  npm run html      — только HTML (python _src/build.py)
  npm run watch     — пересборка при изменении scss
  HTML правится в _src/tpl, не в готовых *.html — иначе затрётся при сборке.
  Готовые HTML/CSS лежат в репозитории, поэтому хостинг сборку не запускает:
  vercel.json отключает установку и сборку на Vercel, GitHub Pages — .nojekyll.

ШРИФТ
  Geometria (400, 500, 700, 800) — fonts/Geometria-*.woff2 / .woff,
  сконвертированы из присланных TTF. Подключение — scss/_fonts.scss.

ШИРИНЫ ЭКРАНА
  > 1920        сайт по центру, по бокам белый фон
  1680          как в макете
  1024–1679     десктоп сужается; <1440 язык/валюта уходят в бургер,
                <1280 пункты меню уходят в бургер
  < 1024        мобильная версия (макет 390), растягивается

ЧТО РАБОТАЕТ (демо для вёрстки, без бэкенда)
  - видео на первом экране главной: зациклено, без звука; браузер сам выбирает
    AV1 или H.264 и версию под ширину экрана; вне экрана — пауза; при «уменьшить
    движение» и экономии трафика — только первый кадр
  - «Контакты»: карта 13 складов (координаты по адресам, геокодер OpenStreetMap);
    клик по адресу в списке — карта переходит к складу
  - шапка закреплена на всех страницах; после прокрутки фон становится плотнее
  - окна поиска, корзины, обратной связи: повторный клик по кнопке закрывает окно
  - выпадающие списки фильтра — свои (кнопка + список), нативный <select> остаётся
    в форме и отправляется как обычно; клавиатура: ↑/↓, Home/End, Enter, Esc
  - карта наличия на главной: город (подсказки из списка), тип, количество →
    склады с ценой, доставкой (км, рейсы), сроком; «Рекомендуем» — самый выгодный;
    клик по складу или метке — маршрут и итог. Данные складов и цен — демо в
    js/ctmap.js, в OpenCart их отдаёт модуль. Маршрут — прямая × 1.25 (не по дорогам),
    подложка — OpenStreetMap (на проде заменить подложкой модуля / своим ключом)
  - «Каталог»: мега-меню по наведению, клик по категории — подкатегории
  - «О нас», телефоны, язык, валюта — выпадающие списки по наведению (на тач — по нажатию)
  - бургер: каталог, подкатегории, «О нас», язык, валюта, поиск
  - поиск: недавние запросы; запрос «пустынный» показывает «ничего не найдено»,
    любой другой — результаты
  - корзина: +/−, удаление, пересчёт суммы; пустая корзина — «Вас может заинтересовать»
  - «Обратная связь» (в меню «О нас» и в подвале) → проверка полей → «Приняли сообщение»
  - слайдеры: по кругу, точка = страница, без автопрокрутки (если карточек мало для
    loop — rewind: с последней страницы «вперёд» ведёт на первую)
  - статья: «Поделитесь статьей» — Telegram / LinkedIn / Facebook с адресом статьи,
    Instagram копирует ссылку (на телефоне — системное «Поделиться»)
  - «О нас»: плитки с цифрами — в шаблоне страницы (в OpenCart — поля/модуль), не в тексте
  - преимущества в первом экране сменяются раз в 2 секунды
  - каталог: фильтр — отметки добавляют/убирают «чипсы» выбранных значений,
    крестик на «чипсе» снимает отметку, группы сворачиваются, у свёрнутой группы
    показывается число отмеченных; на экранах до 1280 фильтр свёрнут в плашку,
    по «+» открывается поверх списка («Сбросить» / «Показать товары»);
    сортировка переключает активный пункт
  - первый экран категории: цвет фона и положение картинки задаются
    переменными в style блока (--bg, --x/--y/--w/--h и --mx/--my/--mw/--mh
    для мобильного) — удобно выводить из настроек категории в OpenCart
  - карточка товара: галерея закреплена при прокрутке, миниатюры — слайдер
    Swiper (фото может быть больше 4), клик по фото — просмотр
    на весь экран (стрелки, ←/→, свайп, Esc), количество +/−,
    «Показать все параметры», подсказка у метки категории (i),
    «Заказать в 1 клик» (проверка номера); когда блок покупки уходит вверх,
    под шапкой появляется панель с ценой и «В корзину»
  - оформление заказа: подписи полей «всплывают» при вводе, обязательные поля
    и согласие с офертой проверяются при отправке (ошибка — оранжевая рамка и
    значок), после проверки — переход на «Заказ принят»; на мобильном
    «Содержимое заказа» — свёрнутая плашка, по «+» открывается список
  - все «Подробнее» / названия товаров ведут на product.html,
    «Показать все» в поиске — на search.html, «Оформить заказ» в корзине —
    на checkout.html

ВРЕМЕННО
  - кнопка «Добавить свой отзыв» пока открывает окно «Обратная связь»
    (отдельной формы отзыва в макете нет)
  - в каталоге и результатах поиска — 24 товара, на мобильном столько же (ТЗ п.10)
  - оформление заказа на мобильном: «Номер дома» и «Номер квартиры» выведены
    строкой под «Улицей» (в мобильном макете эти поля сжаты до нуля)
  - поле «Электронная почта» в макете показано в состоянии ошибки — в вёрстке
    это состояние появляется при попытке отправить форму с ошибкой
